# Travel UI 제품 결정 (초기)

## 여행자 중심 동선
탐색 → 장소 상세 → 여행 동기(공식·방송/크리에이터) → 언제 갈까(계절·휴관) → 어떻게 갈까(항공/철도/버스/배/렌터카) → 어디서 잘까(호텔/숙소) → 뭘 먹을까(외부 검증 맛집) → 개별 예약/패키지/홈쇼핑 비교 → 예상 총비용.

## 탐색
- 국내/해외 탭 + 지역·관심사 필터
- 이번 주말, 이번 달 등의 날짜별 조회는 실제 날짜/시차 검증 후 활성화
- 유형: 관광지/축제/쉼·휴식/숨은 명소/교통/숙박/패키지/맛집
- 매체별 탐색: 공식 안내, 여행 유튜버(빠니보틀·곽준빈 등), 여행 TV, 현지 블로거.
- 같은 여행지를 사람별로 중복 카드로 내지 않고 '장소 본체 + 여행 이야기·영상·방송 단서'로 연결.

## 비용 UX
날짜, 출발지, 목적지, 인원, 교통수단, 호텔 등급, 객실, 식사 선택에 따라 검색된 가격과 계산 추정을 나란히 비교하되 실시간 재고는 절대 암시하지 않는다.
초기 구현은 **사용자가 직접 입력하는 예산 계산기**이며 공급사 실시간 요금과 무관함을 명시.
통화 혼합 금지; 환율 출처 확인 없는 원화 환산 금지.
`/go/id` 버튼은 서버 링크 매핑이 구축/검증되기 전까지 표시하지 않는다.

## 별도 맛집 프로젝트 연계
외부 프로젝트의 검수된 명소·식당 공개 ID를 계약 v1로 연결하고, 지역·좌표 검증이 되지 않으면 주변 맛집으로 자동 추천하지 않는다.

## 공급원
TourAPI 공식 여행정보, 해외 관광청, 유튜브·방송·블로그의 여행지 단서, 숙박 OTA·여행사·홈쇼핑 공식/제휴 제공 자료. 자료 사용·번역·이미지 저작권과 각 소스 조건 준수.

## 보안/SEO
데이터 소스 자체는 공개하지 않되 페이지는 탐색기와 검색엔진에서 찾을 수 있도록 유익한 검증 요약을 제공. 출처 유형·검증일은 남김. 정적 JSON을 제공한 만큼 누구나 다운로드할 수 있으므로 추후 서버 검색/페이지네이션을 별도 설계.

## 2026-10-09 공식 장소 3건 선공개 정책
- 제주시 사려니숲길, 부산 감천문화마을, 일본 교토 아라시야마는 정부/관광청·관광공사의 해당 장소 안내를 직접 확인한 고정 사실만 공개한다.
- 3개 모두 확정 실시간 요금과 개별 업체의 예약 재고·시간이 없으므로 가격은 **unknown**으로 둔다.
- 사용자 카드 클릭 → `?place=<public_id>` 상세 → 방문 참고 및 교통/숙박/맛집/여행상품/콘텐츠 준비 상태 → 직접 예상 경비 계산.
- 방송·유튜버·블로그 실영상 출처와 연결은 근거 검토 후에만 연다. 공식 원본 URL은 Public에 넣지 않는다. 서버 리디렉션 준비 전 '공식 링크' 버튼도 만들지 않는다.
- 현재 정적 페이지의 JS 기반 상세는 검색엔진에 각 페이지를 확실히 색인하는 구조가 아님. 대량 성장 시 SSR/사전 생성 또는 서버 렌더링 검토.
